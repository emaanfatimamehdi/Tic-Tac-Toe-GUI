## Tic Tac Toe GUI
This is a simple Tic Tac Toe game developed using Python and Tkinter. It provides a graphical interface where two players can play Tic Tac Toe.

## Features

- Graphical User Interface (GUI)
- Two-player gameplay
- Interactive game board
- Simple and user-friendly design
- Python-based game logic

## Technologies Used

- Python
- Tkinter

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Run the "TicTacToe.py" file using Python.

## Project Purpose

This project was developed to practice Python programming, GUI development, conditional logic, and game development fundamentals.
